# 🛡️ Решение проблем с антивирусами

## Проблема

Некоторые антивирусы блокируют установщик Windows приложения, даже если оно безопасно. Это происходит потому, что:
- Приложение не подписано цифровой подписью (Code Signing)
- Антивирусы используют эвристический анализ
- Недостаточно репутации у нового приложения

## ✅ Решение: Portable версия

**Portable версия** - это лучший способ обойти блокировки антивирусов, так как:
- ✅ Не требует установки (не изменяет системные файлы)
- ✅ Не требует прав администратора
- ✅ Меньше подозрений у антивирусов
- ✅ Можно запускать с USB-флешки
- ✅ Легко добавить в исключения

## 📦 Использование Portable версии

### Шаг 1: Скачайте Portable версию

Скачайте файл: **`PhotoApp-Portable-v*.zip`** (не установщик!)

### Шаг 2: Распакуйте архив

Распакуйте в любую папку, например:
- `C:\Program Files\PhotoApp\`
- `D:\Apps\PhotoApp\`
- `C:\Users\ВашеИмя\Desktop\PhotoApp\`

### Шаг 3: Запустите приложение

Дважды кликните на:
- `photo_app_client.exe` (основной файл)
- ИЛИ `Запустить.bat` (ярлык для быстрого запуска)

**Готово!** Приложение работает без установки.

## 🔧 Если антивирус все равно блокирует

### Способ 1: Добавить в исключения (рекомендуется)

#### Windows Defender (встроенный антивирус):

1. Откройте **Параметры Windows** (Win+I)
2. Перейдите в **Безопасность Windows**
3. Нажмите **Защита от вирусов и угроз**
4. Прокрутите вниз и нажмите **Управление настройками**
5. Прокрутите до **Исключения** и нажмите **Добавить или удалить исключения**
6. Нажмите **Добавить исключение** → **Папка**
7. Выберите папку, куда вы распаковали приложение
8. Нажмите **Выбрать папку**

#### Другие популярные антивирусы:

**Kaspersky:**
1. Откройте Kaspersky → **Настройки**
2. **Дополнительно** → **Угрозы и исключения**
3. **Исключения** → **Добавить**
4. Выберите папку с приложением

**Avast:**
1. Откройте Avast → **Настройки**
2. **Общие** → **Исключения**
3. **Добавить** → Выберите папку

**Norton:**
1. Откройте Norton → **Настройки**
2. **Антивирус** → **Исключения/Низкий риск**
3. **Добавить** → Выберите папку

**McAfee:**
1. Откройте McAfee → **Настройки**
2. **Исключения** → **Добавить файл/папку**
3. Выберите папку

**ESET:**
1. Откройте ESET → **Настройки**
2. **Основные** → **Исключения**
3. **Добавить** → Выберите папку

### Способ 2: Запуск из командной строки

Если антивирус блокирует запуск двойным кликом:

1. Нажмите **Win+R**
2. Введите `cmd` и нажмите Enter
3. Перейдите в папку с приложением:
   ```cmd
   cd "C:\путь\к\приложению"
   ```
4. Запустите:
   ```cmd
   photo_app_client.exe
   ```

### Способ 3: Временно отключить защиту (не рекомендуется)

⚠️ **Только для одноразового запуска!**

1. Временно отключите защиту антивируса
2. Запустите приложение
3. **Сразу включите защиту обратно!**

## 🔐 Безопасность

**Приложение безопасно!** Антивирусы блокируют его из-за:
- Отсутствия цифровой подписи (Code Signing стоит $200-400/год)
- Недостаточной репутации у нового приложения
- Эвристического анализа (ложные срабатывания)

**Вы можете:**
- Проверить файлы через VirusTotal: https://www.virustotal.com/
- Запустить в изолированной среде (виртуальная машина)
- Изучить исходный код (приложение с открытым исходным кодом)
