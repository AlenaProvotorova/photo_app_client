# 🔒 Решение проблемы с сертификатом и Mixed Content

## Проблема
Браузер показывает "Resources - active content with certificate errors", что означает, что некоторые ресурсы загружаются с ошибками сертификата.

## Шаги для решения

### 1. Очистка разрешений браузера на загрузку небезопасного контента

#### Chrome:
1. Откройте `chrome://settings/content/insecureContent`
2. Найдите `fastselect.ru` в списке "Разрешенные сайты"
3. Удалите его из списка
4. Или используйте команду в адресной строке:
   ```
   chrome://settings/content/insecureContent
   ```
   И удалите `fastselect.ru` из списка разрешенных

#### Альтернативный способ:
1. Откройте DevTools (F12)
2. Перейдите на вкладку **Security**
3. Нажмите на **"View certificate"** для проблемных ресурсов
4. В настройках сайта (иконка замка в адресной строке) → **Настройки сайта** → **Небезопасный контент** → Удалите разрешения

### 2. Проверка сертификата API

Проверьте сертификат на `api.fastselect.ru`:

```bash
# Проверка сертификата через openssl
openssl s_client -connect api.fastselect.ru:443 -showcerts

# Или через curl
curl -vI https://api.fastselect.ru/api/
```

**Проблемы, которые могут быть:**
- Самоподписанный сертификат
- Истекший сертификат
- Неполная цепочка сертификатов
- Несоответствие домена (CN или SAN не содержит api.fastselect.ru)

### 3. Проверка в браузере

1. Откройте DevTools (F12)
2. Перейдите на вкладку **Network**
3. Обновите страницу (Ctrl+R или Cmd+R)
4. Найдите запросы с ошибками (красные или с предупреждениями)
5. Проверьте:
   - Какие URL вызывают ошибки
   - Какой статус у запросов
   - Есть ли ошибки сертификата в деталях запроса

### 4. Проверка консоли браузера

Откройте Console в DevTools и проверьте:
- Есть ли ошибки загрузки изображений
- Какие URL используются для загрузки
- Есть ли сообщения о сертификатах

### 5. Проверка сертификата через веб-интерфейс

1. Откройте `https://api.fastselect.ru` в браузере
2. Нажмите на иконку замка в адресной строке
3. Проверьте сертификат:
   - Должен быть валидным
   - Должен быть выдан доверенным центром сертификации
   - Не должен быть самоподписанным

### 6. Решение на стороне сервера

Если сертификат на `api.fastselect.ru` невалиден:

1. **Установите валидный SSL сертификат:**
   ```bash
   # Используйте Let's Encrypt (бесплатный)
   certbot --nginx -d api.fastselect.ru
   
   # Или через панель управления reg.ru
   # ISPmanager → SSL сертификаты → Установить Let's Encrypt
   ```

2. **Проверьте конфигурацию Nginx/Apache:**
   - Убедитесь, что сертификат правильно настроен
   - Проверьте цепочку сертификатов (intermediate certificates)
   - Убедитесь, что редирект HTTP → HTTPS работает

### 7. Временное решение (только для тестирования)

Если нужно временно разрешить небезопасный контент для тестирования:

1. Chrome: `chrome://flags/#unsafely-treat-insecure-origin-as-secure`
2. Добавьте `https://fastselect.ru` в список
3. **ВАЖНО:** Это только для разработки! Не используйте в продакшене!

## Диагностика через код

Код уже логирует все URL изображений в консоль браузера. Проверьте консоль и найдите:
- `📸 Image URL (full): ...` - полные URL
- `📸 Image URL (constructed): ...` - сформированные URL
- `❌ Image load error for URL: ...` - ошибки загрузки

## Проверка после исправления

1. Очистите кэш браузера полностью
2. Закройте все вкладки с `fastselect.ru`
3. Откройте сайт заново
4. Проверьте DevTools → Security
5. Должно быть: "This page is secure" без предупреждений

## Контакты для помощи

Если проблема сохраняется:
1. Сделайте скриншот DevTools → Network с проблемными запросами
2. Проверьте сертификат через SSL Labs: https://www.ssllabs.com/ssltest/analyze.html?d=api.fastselect.ru
3. Проверьте логи сервера на наличие ошибок SSL
